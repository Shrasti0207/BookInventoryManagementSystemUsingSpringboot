# Book Inventory Management System
This is a Spring Boot application for managing books in an inventory. It allows adding, updating, searching, deleting, and purchasing books.

## Features
- Add a new book
- View all books
- Find a book by ISBN
- Search books by title
- Update book details
- Delete a book
- Purchase a book (with stock validation)

## Technologies Used
- Java, Spring Boot, Spring Data JPA
- H2 Database (for testing) / MySQL (for production)
- Maven (build tool)

## How to Run
1. Clone the repository: git clone https://github.com/Shrasti0207/BookInventoryManagementSystemUsingSpringboot.git
2. Configure database
3. Build and run the project
